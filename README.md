## Layout

```
_quarto.yml            website project (renders to _site/, not committed)
.github/workflows/     publish.yml: renders and deploys the site to GitHub Pages on every push
index.qmd              course home page (cards, updates: generated pieces _chapters.md, _updates.md)
contents.qmd, problems.qmd  generated slide contents and problem index
tools/chapters.py      single source of truth for chapters (title, topics, thumbnail, widgets)
tools/build_index.py   writes the generated pieces + the table above (Quarto pre-render)
assets/procon.css      slide theme + print rules (shared by all chapters)
tools/                 make_pdf.py, make_handout.py, build_chapter.sh, svgdiagram.py (shared SVG diagram helper)
ch4/
  ch4_stability.qmd    reveal.js deck (Python/MATLAB code tabs)
  figures/             generated by make_figures.py
  diagrams/            hand-drawn inline-SVG diagrams (included with {{< include >}})
  interactive/         Kc-slider root-locus widget (+ standalone page)
  routh.py             sympy Routh array (epsilon and zero-row cases)
  ch4_stability.ipynb  companion notebook (generated by build_notebook.py)
  *.pdf                slides (1 per page) and A4 handout (3 per page + note lines)
```

## Publishing

Push to `main` — GitHub Actions renders the site and deploys it (Settings → Pages → Source: **GitHub Actions**).
PDFs, figures and notebooks are built locally and committed in each `chN/` folder.

## Build a chapter locally

```bash
pip install control sympy scipy matplotlib nbformat playwright pymupdf
playwright install chromium
tools/build_chapter.sh ch1 ch1_dynamics "Ch. 1 Mathematical Preliminaries & Dynamic Response"
tools/build_chapter.sh ch2 ch2_analysis "Ch. 2 Analysis of Single-Loop Control Systems"
tools/build_chapter.sh ch3 ch3_tuning "Ch. 3 Tuning of Single-Loop Control Systems"
tools/build_chapter.sh ch4 ch4_stability "Ch. 4 Stability of Closed-Loop Systems"
tools/build_chapter.sh ch5 ch5_frequency "Ch. 5 Frequency-Response Analysis & Design"
tools/build_chapter.sh ch6 ch6_multiloop "Ch. 6 Multi-loop Systems"
```

`NEW` / `FIX` review badges in the slides are hidden by a rule at the end of `assets/procon.css`.
